# Slice contract S5 — line-ending + BOM seam fixes

- AC-1: inserts or updates a TOC between the markers idempotently for LF, CRLF, and CR-only files alike; only the line terminators CRLF, CR, LF split lines (exotic Unicode separators never split a heading); inserted lines use the file's first-seen terminator; nested indent is relative so a TOC never renders as an indented code block.
- AC-6: without markers, insert after the first H1 else at the top; a UTF-8 BOM stays at byte 0 and does not hide the first heading.
