orca orchestration task-update

Usage: orca orchestration task-update --id <task_id> --status <status> [--result <text>] [--run <run_id>] [--from <handle>] [--retry-request <id>] [--json]

Update a task status

Options:
  --help                 Show this help message
  --json                 Emit machine-readable JSON
  --pairing-code
  --environment
  --id <id>             Identifier for a target item or permission
  --status
  --result
  --run
  --from
  --retry-request

Notes:
  Valid --status values: pending, ready, dispatched, completed, failed, blocked.
  To cancel a Task, stop or abandon its worker, then set --status failed --result cancelled; a later worker-start --retry-of reopens it.
