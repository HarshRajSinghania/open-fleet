## No-regression probes
- **CRLF doc** `# T\r\n## A\r\n` returns `'# T\r\n\r\n<!-- toc -->\r\n- [A](#a)\r\n<!-- /toc -->\r\n\r\n## A\r\n'`, idempotent. Covered by `tests/test_update.py:63` and `:113`.
- **Mixed-EOL** `# T\n## A\r\n### B\r` returns `'# T\n\n<!-- toc -->\n- [A](#a)\n  - [B](#b)\n<!-- /toc -->\n\n## A\r\n### B\r'`. The first-seen terminator (LF) wins for inserted lines, original lines are untouched, and it is idempotent.
- **First line ends CR, then CRLF** `# T\r## A\r\n### B\r\n` returns `'# T\r\r<!-- toc -->\r- [A](#a)\r  - [B](#b)\r<!-- /toc -->\r\r## A\r\n### B\r\n'`. CR (first seen) wins and the result is stable.
- **BOM-only file** returns `'﻿<!-- toc -->\n<!-- /toc -->\n'`, idempotent.
- **Empty file** returns the same marker block with no BOM, idempotent.
- **File exactly `\r`** returns `'<!-- toc -->\r<!-- /toc -->\r\r\r'`, idempotent. The trailing padding mirrors the LF `"\n"` case (`elif h1 is None and rest: block += eol`) and is cosmetic.
- **BOM after a leading blank line** `\n﻿# T\n## A\n` returns `'<!-- toc -->\n- [A](#a)\n<!-- /toc -->\n\n\n﻿# T\n## A\n'`. The BOM is literal text, not byte 0, so it is not stripped and H1 is not recognised there. This is the correct reading of AC-6, and it is idempotent.
